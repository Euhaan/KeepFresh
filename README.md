# 킵프레시 · 우리집 냉장고

킵프레시(KeepFresh)는 가족이 함께 쓰는 냉장고 관리 앱입니다. 신선함을 지킨다는 뜻이고, 패키지 이름은 keepfresh입니다(로컬 폴더는 초기 가칭이던 KanKan 그대로). 냉장실·냉동실·김치냉장고의 어느 칸에 무엇이 있고 언제까지 먹어야 하는지 보여주고, 임박한 재료로 만들 수 있는 요리를 추천합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 폰에서는 "홈 화면에 추가"로 설치할 수 있습니다(PWA).

```bash
npm test        # 기한 규칙, 이벤트 합산, 요리 매칭 테스트
npm run build   # 타입 검사 + 번들
```

## 구조

```
src/domain/     순수 로직. React와 무관
  types.ts      가정 → 보관소 → 칸 → 품목 모델
  presets.ts    공용 식품 사전 (통상 보관기간, 예시 값)
  expiry.ts     기한 계산 우선순위: 직접 > 해동 > 냉동 > 표기·개봉 > 기준일·구매일 + 통상
  events.ts     모든 변경은 이벤트. 수량은 증감으로 기록
  actions.ts    사용자 동작 → 이벤트 + 되돌리기 이벤트
  dishes.ts     지금 있는 재료로 만들 수 있는 요리 목록 (보유 비율 + 임박 가중 - 부족 벌점)
  seed.ts       데모 데이터 (김씨네, 자취방)
src/store/      이벤트 로그 저장(localStorage)과 Supabase 동기화 어댑터
src/ui/         화면: 홈, 냉장고, 등록, 요리, 장보기, 가족·설정
supabase/       스키마, RLS 정책, 연결 방법
```

## 지금 되는 것

- 냉장고 단면 그림으로 보는 칸(위 칸·중앙 칸·아래 칸·도어), 칸 안의 재료 아이콘과 임박·지남 점
- 전역 검색, 기한 칩과 근거 뱃지(직접·표기·개봉·통상), 분류별 아이콘 타일
- 홈의 이번 주 기한 타임라인, 상단 알림함(챙길 것 개수 뱃지, 먹음·+3일 바로 처리)
- 브라우저 알림: 권한을 허용하면 설정한 아침 시간에 임박·지남 요약 한 건 (앱이 열려 있거나 백그라운드일 때)
- 먹음·버림·기한 연장·개봉·냉동 이동·해동·재냉동 경고·칸 이동, 모두 5초 되돌리기
- 다시 샀어요 칩, 두 글자 자동완성, 날짜 칩, 장본 날 모드, 중복 합치기
- 다 먹으면 장보기 자동 추가, 체크한 것 냉장고에 넣기
- 지금 있는 재료로 만들 수 있는 요리 목록(바로 가능·하나만 더·더 사면), 없는 재료 장보기 추가, 만들었어요로 재료 차감. 조리법은 다루지 않음
- 가정 전환(데이터 완전 분리), 식품 사전 가정별 덮어쓰기, 알림 설정 저장
- 오프라인 동작, 설치형 PWA
