# 킵프레시 서버 (Supabase)

앱은 서버 없이도 기기 안에서 동작합니다. 가족 간 실시간 공유를 켜려면 아래 순서로 연결하세요.

1. supabase.com에서 프로젝트를 만들고 SQL 편집기에서 `migrations/0001_init.sql`을 실행합니다.
2. 프로젝트 설정의 API 탭에서 URL과 anon 키를 복사해 루트의 `.env`에 넣습니다 (`.env.example` 참고).
3. Authentication에서 이메일 OTP 또는 카카오 로그인을 켭니다. 앱 쪽 로그인 화면은 아직 없으며 다음 단계입니다.
4. 가정을 만들면 `households`와 `memberships`에 행이 생기고, 그 뒤 모든 변경은 `events`에 추가됩니다.

## 설계 메모

- 모든 표에 `household_id`가 있고, 접근은 `memberships`를 통해 행 수준 보안(RLS)으로 막습니다. 앱 코드가 필터를 빠뜨려도 다른 가정의 행은 보이지 않습니다.
- `events`는 추가 전용입니다. 수량은 증감으로 기록되어 동시 편집과 오프라인 충돌이 합산으로 풀립니다. 되돌리기는 보상 이벤트입니다.
- 보기 전용 역할은 `ITEM_QTY`(먹음)와 `SHOP_PATCH`(장보기 체크)만 올릴 수 있습니다.
- 공용 식품 사전과 바코드 카탈로그는 읽기 전용이며 서버 함수(service role)만 씁니다.

## 아직 안 한 것

- 로그인 화면과 초대 코드로 가입하는 흐름
- 아침 요약 푸시(Edge Function + 예약 작업)
- 이벤트가 많이 쌓인 가정을 위한 스냅샷 표
- 실제 프로젝트에 대고 RLS 정책과 실시간 구독을 검증하는 일
